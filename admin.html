How do I get a token?
  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Name it “Portfolio admin” and set an expiration.
  3. Under Repository access, choose Only select repositories → portfolio.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate, copy, and paste it above. Treat it like a password; never put it in the website's code.
